# Security Policy

## Safe use

This is a defensive portfolio lab that contains only synthetic data. Do not
submit real sensitive data, credentials, security tokens, production logs, or
details about systems you do not own or have explicit authorization to test.

## Reporting a repository issue

If you find a flaw in the lab code, a synthetic fixture that could be
misunderstood as real data, or an unsafe instruction, open a private security
advisory in the published repository when available. Include a minimal
reproduction and do not publish secrets or operational details in an issue.

## Scope

The runnable detector is educational. It is not a production SIEM, incident
automation platform, business system, or compliance-control implementation.
